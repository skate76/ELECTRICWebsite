01 — About

What is this project?

This is a budget-constrained electricity usage optimization system designed for households — particularly those navigating the high electricity costs in Jamaica. The system allows users to plan and manage their appliance usage so that total projected electricity costs never exceed their monthly budget.

Rather than guessing how long to run each appliance, the system performs precise calculations using known appliance power ratings (watts/kW), electricity rates (cost per kWh), and user-defined constraints to determine the optimal daily usage duration for each appliance — maximizing comfort while respecting financial limits.

Household Budgeting Electricity Optimization Linear Programming
02 — How It Works

How does it work?

The system models electricity as a scarce resource and formulates the problem as a linear programming optimization. Users input their monthly budget, their appliances, and constraints like priority and maximum usage time. From there, the system takes over:

  1. 1
    Convert usage to cost — appliance watt ratings and billing days are used to compute kWh consumption and the cost contribution of each appliance.
  2. 2
    Run the LP solver — a Linear Programming model maximizes total usage time across all appliances subject to budget and per-appliance constraints.
  3. 3
    Output the optimal plan — the system returns recommended daily hours per appliance, a full cost breakdown, and a pie chart visualization.
  4. 4
    Test What-If scenarios — add a new appliance, adjust usage time, or modify your budget to instantly see the updated plan and its cost impact.
03 — Why Use It

Why would you want this?

Manual electricity budgeting is unreliable. Appliances draw different wattages, run for different durations, and electricity rates are largely unknown to the average consumer. This leads to inconsistent tracking, no actionable feedback, and recurring overspend. This system solves that with automation and mathematical precision.
